# Талон — перший доступний час

Версія 0.1.5 для Chrome. Цільовий сервісний центр за замовчуванням: №2641, Івано-Франківськ. Помічник обирає найранішу доступну дату та перший за часом слот без обмеження години.

## Встановлення оновлення

1. На сторінці `chrome://extensions` видаліть попереднє розширення «Талон — особистий помічник СЦ».
2. Увімкніть «Режим розробника», натисніть «Завантажити розпаковане розширення» та оберіть папку `Талон — перший доступний час 0.1.5` на робочому столі. Не встановлюйте обидві версії одночасно.
3. Оновіть вкладку Е-запису. На панелі має бути версія 0.1.5.

## Запуск

1. Самостійно увійдіть у Е-запис, оберіть практичний іспит, авто та категорію. Залишіться на карті сервісних центрів.
2. Перевірте номер СЦ 2641. Для проби без запису ввімкніть «Перевірка без бронювання» й натисніть «Почати зараз».
3. Для пошуку талона о 06:00 натисніть «Чекати 06:00» приблизно о 05:59:30. Якщо вже минула шоста, натисніть «Почати зараз».
4. Тримайте вкладку відкритою на екрані та комп’ютер активним. Після вибору часу пройдіть CAPTCHA на сайті самостійно. Якщо сайт запросить телефон або e-mail, заповніть їх.
5. Перевірте номер талона в особистому кабінеті. «Стоп» або Esc зупиняють подальші дії.

У реальному режимі після вашої CAPTCHA помічник натисне «Далі» та завершить запис, коли сайт дозволить. У режимі перевірки він зупиниться після вибору часу й не надішле бронювання. Реальний запис у цій версії не тестувався.

## Оновлення сторінки

Сторінку вручну не перезавантажуйте під час роботи помічника. У перевіреному фронтенді сайт сам оновлює список центрів і дат приблизно кожні 30 секунд, а список годин — кожні 5 секунд. Помічник стежить за появою доступної кнопки та діє відразу. О 06:00 він один раз повертається через вибір послуги, щоб відкрити свіжу карту. Якщо штатні запити центрів не надходили 90 секунд, виконує резервне оновлення тим самим шляхом. Коротші інтервали більше не пропонуються.

Пошук триває до 30 хвилин після запуску. Якщо вкладка прихована понад 30 секунд, сесія завершилася, сайт показав помилку або відповів HTTP 429, помічник зупиняється. CAPTCHA очікується до 2 хвилин. Один запуск не гарантує наявності талона.
